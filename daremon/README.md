# DAREMON.NL

**Onafhankelijke Analyse van Lokaal Beleid**

## 📋 Overzicht

DAREMON is een platform voor kritische, data-gedreven analyse van lokaal beleid in Noord-Brabant. Het project richt zich op huisvestingsbeleid, migratiestrategieën en langetermijneffecten op lokale gemeenschappen.

## 🎨 Design Principes

### Kleurenpalet

De website gebruikt een professioneel donker kleurenschema met Nederlandse accenten:

**Hoofdkleuren:**
- `#0A0E27` - Donker blauw (hoofdachtergrond)
- `#1A1D35` - Secundair donker (kaarten/secties)
- `#252942` - Tertiair donker (hover states)

**Oranje Accenten:**
- `#FF6200` - Primair oranje (hoofdaccent)
- `#FF8534` - Licht oranje (hover)
- `#E55800` - Donker oranje (pressed state)

**Nederlandse Vlag Accenten:**
- `#AE1C28` - Rood (prioriteitslabels, alerts)
- `#21468B` - Blauw (links, secundaire accenten)
- `#F8F9FA` - Wit (hoofdtekst)

### Typografie

- Font Family: 'Inter' met fallbacks naar systeem fonts
- Schaalbare groottes voor responsive design
- Duidelijke hiërarchie met font weights 400-900

## ✨ Belangrijkste Elementen

### 1. **Header met Nederlandse Vlag Border**
Sticky header met gradient border in Nederlandse vlagkleuren

### 2. **Hero Section**
Grote kop met orange highlight en transparante tagline

### 3. **Mission Statement**
Orange border-left accent voor visuele nadruk

### 4. **Category Cards**
Hover effecten met Nederlandse vlag gradient bij top

### 5. **Analysis Cards**
Priority tags in rood, standaard tags in blauw

### 6. **Stats Section**
Grote cijfers met orange gradient voor impact

### 7. **About Section**
Persoonlijke informatie met credential badges

### 8. **Footer**
Nederlandse vlag gradient border met structuur in 3 kolommen

## 📱 Responsive Design

De website is volledig responsive met breakpoints bij 768px:
- Desktop: volledig grid layout
- Tablet/Mobile: gestapelde layouts met verborgen navigatie

## 🎯 Kluczowe Cechy
